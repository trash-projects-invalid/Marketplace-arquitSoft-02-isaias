# Actores del sistema

Este documento identifica los actores (personas, organizaciones o sistemas externos) que interactúan con el marketplace de productos para mascotas.

## Actores

| Actor                   | Descripción                                                                      | ¿Qué necesita realizar?                                                                                                                      |
| ----------------------- | -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| Cliente                 | Persona que busca y compra productos para sus mascotas a través del marketplace. | Buscar productos, consultar información, agregar productos al carrito, realizar pedidos, efectuar el pago y consultar sus pedidos.           |
| Seller                  | Vendedor registrado en la plataforma que ofrece productos para mascotas.         | Ofrecer productos, registrar productos, actualizar productos, consultar sus productos y gestionar la información relacionada con sus ventas. |
| Administrador           | Persona encargada de gestionar la plataforma.                                    | Administrar la plataforma.                                                                                                                   |
| Pasarela de pago        | Sistema externo que procesa los pagos de los pedidos.                            | Procesar pagos.                                                                                                                              |
| Servicio de envío       | Sistema externo encargado de la logística de entrega.                            | Gestionar información de entrega.                                                                                                            |
| Servicio de Facturación | Sistema externo responsable de la emisión de comprobantes.                       | Generar comprobantes de pago.                                                                                                                |
| ERP                     | Sistema externo de planificación de recursos de la empresa.                      | Proporcionar información de productos y stock.                                                                                               |
